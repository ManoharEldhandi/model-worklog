# model-worklog-schema

Versioned TypeScript types and validators for Model Logger sessions, events, evidence grades, and supervisor health responses.

```sh
npm install model-worklog-schema
```

Use it when building an adapter, client, or reader that needs to validate Model Logger evidence. Full documentation: [Model Logger](https://github.com/ManoharEldhandi/model-worklog). Use is subject to the included license.

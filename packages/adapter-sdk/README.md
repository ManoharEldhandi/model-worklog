# model-worklog-sdk

Local client SDK for recording observable AI-product activity in Model Logger. It communicates only with a loopback supervisor using its local credential.

```sh
npm install model-worklog-sdk
```

Start a session with `LocalSupervisorClient`, record visible messages, tools, files, tests, and provider usage, then complete it. Never submit private chain-of-thought. See the [integration guide](https://github.com/ManoharEldhandi/model-worklog/blob/main/docs/integration.md). Use is subject to the included license.

# Security policy

Please do not disclose security vulnerabilities in public issues. Report them through the repository's [private security-advisory form](https://github.com/ManoharEldhandi/model-worklog/security/advisories/new) with reproduction steps, impact, and a safe contact method.

Model Logger is designed for local-only operation. Reports involving evidence redaction, loopback binding, workspace trust, credential handling, path scrubbing, or evidence-bundle integrity are especially important.

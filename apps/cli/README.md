# model-worklog

Command-line interface for local Model Logger sessions.

```sh
npm install -g model-worklog
model-worklog supervisor start
model-worklog workspace trust .
model-worklog sessions list
```

Use `model-worklog logs <session-id>` to review a session and `model-worklog export <session-id> --output session.json` for a redacted evidence bundle. Full documentation: [Model Logger](https://github.com/ManoharEldhandi/model-worklog). Use is subject to the included license.
